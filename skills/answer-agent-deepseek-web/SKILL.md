# 固定操作，少用 token

默认由脚本完成可确定的采集、复制、上传、等待、捕获、版本检查和台账更新，不把每个步骤交给 Agent 规划或截图判断，不默认开 subagent。仅脚本无法定位或出现新布局时使用一次必要的 Luna 定位；已确认流程回到脚本执行。教学与必要语义判断才使用 DeepSeek/既有教学 Skill。

固定步骤直接运行 CLI；确需模型定位时只由一个 GPT-6 Luna low 串行操作，教学交 DeepSeek 和冻结 ANSWER。使用当前业务仓库、run、版本、会话与阶段授权；不新增服务、Profile、消息通道或权限。

当前优先本机 ego-lite：[固定 CLI 流程](references/ego-lite.md)。复用当前 TaskSpace、Page 和业务会话；直接 DOM 上传、提交及捕获，不走桌面坐标。网页输出仍须业务核验，不能冒充已交付。

以原任务冻结的 ego_policy 为准。新验收任务使用 MATCH_THEN_TEACH：程序先发送原图与实际 Top2 候选，取得结构化核验结果；再在同一会话上传 ANSWER 原文，按学生原话/题号生成自然语言教学稿。结构化要求只用于核验阶段，由程序构造，不让执行 Agent 手写或重述。旧 DIRECT_ORIGINAL 任务按原策略恢复，不能静默改成两阶段。

用户长期授权（2026-10-19）：本项目的 ego TaskSpace 确已丢失时，始终允许重建一个任务空间继续原任务，无需再次询问；此明确授权优先于 ego 通用 Skill 的“不得新建空间恢复”限制。先查实际空间列表和原请求状态，保留原记录并记录新旧空间关系；仅在确认未提交时恢复准备。已提交或结果未知时只读核验原会话，不因重建空间重发网页请求或企业微信消息；不循环新建、不换 Profile、不扩大收件人或外发授权。

1. 先用程序读取当前 run 和提交/捕获记录，核验文件与冻结 manifest。有提交记录就读取原会话，未知动作不重放。AckTask 独立；历史练习不补发。
2. 复用现有自动答疑队列执行检索和核验；未配置检索不冒充已搜索。原图只在首阶段上传，候选不足两个不补造，核验不通过不进入教学。
3. 教学阶段在同一会话上传对应 ANSWER 原文，程序附带已核验版本结果，捕获自然语言答案并保存草稿。普通追问复用会话、核验与课程，只补本轮原话及必要的实际交付内容；实质更正重新处理当前版本。不要逐步截图或增加独立模型审核。
4. 按当前阶段进入原 Outbox/DeliveryBatch；草稿、部分成功及 UNKNOWN 不算完成或绩效。更正使旧答案停发。

执行优先级：现有 CLI → 程序读取文字控件 → 固定快捷键/本轮有效位置 → 截图兜底。能直接执行就不截图确认位置；连续动作批量执行，每步成功才继续，错误或未知立即停止。保持原输入前台守卫；窗口身份、几何或布局变化时废弃旧位置。上传完成、正确 SID 和完整 prompt 合并为一次提交前文字检查；结果直接捕获原文。

原树、回复和课程保存在私有文件，不反复灌入上下文。正常只返回阶段、程序结果、证据路径；不复述步骤、不额外调用模型审核。实际调用及可取得的 token 用既有计量记录。

仅当入口、控件、上传或捕获需要排障时读取 [Windows-MCP 细节](references/windows-mcp.md)。验证码、人工接管或未知副作用按已有状态停止，轮询原句柄；不无限点击、刷新或重提。
