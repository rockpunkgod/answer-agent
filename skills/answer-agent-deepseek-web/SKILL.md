# 固定操作，少用 token

固定步骤直接运行 CLI；确需模型定位时只由一个 Luna medium 串行操作，教学交 DeepSeek 和冻结 ANSWER。使用当前业务仓库、run、版本、会话与阶段授权；不新增服务、Profile、消息通道或权限。

当前优先本机 ego-lite：[固定 CLI 流程](references/ego-lite.md)。复用当前 TaskSpace、Page 和业务会话；直接 DOM 上传、提交及捕获，不走桌面坐标。网页输出仍须业务核验，不能冒充已交付。

给 DeepSeek 只上传原图和教学原文，文字直接写题号或复制学生原话；不加上下文 JSON、JSON 输出要求、BEGIN/END 标记。

1. 先用程序读取当前 run 和提交/捕获记录，核验文件与冻结 manifest。有提交记录就读取原会话，未知动作不重放。AckTask 独立；历史练习不补发。
2. 学生版本及已有检索结果在本机核验；未配置检索不冒充已搜索。网页只上传必要原图和教学原文，直接写题号或学生原话，不附内部结构化上下文。
3. 同一会话上传对应 ANSWER 原文和原图，发送题号或原话，捕获自然语言答案并保存草稿。保留原教学检查，不重新总结教学。普通追问复用会话与课程，只补本轮原话及必要的实际交付内容。
4. 按当前阶段进入原 Outbox/DeliveryBatch；草稿、部分成功及 UNKNOWN 不算完成或绩效。更正使旧答案停发。

执行优先级：现有 CLI → 程序读取文字控件 → 固定快捷键/本轮有效位置 → 截图兜底。能直接执行就不截图确认位置；连续动作批量执行，每步成功才继续，错误或未知立即停止。保持原输入前台守卫；窗口身份、几何或布局变化时废弃旧位置。上传完成、正确 SID 和完整 prompt 合并为一次提交前文字检查；结果直接捕获原文。

原树、回复和课程保存在私有文件，不反复灌入上下文。正常只返回阶段、程序结果、证据路径；不复述步骤、不额外调用模型审核。实际调用及可取得的 token 用既有计量记录。

仅当入口、控件、上传或捕获需要排障时读取 [Windows-MCP 细节](references/windows-mcp.md)。验证码、人工接管或未知副作用按已有状态停止，轮询原句柄；不无限点击、刷新或重提。
